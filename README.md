# Meu Cuidado

Aplicativo web para acompanhar medicamentos e registrar como você se sente ao longo do tratamento.

## Funcionalidades iniciais
- Cadastrar medicamento, dose e horário
- Marcar tomadas diárias
- Registrar sintomas, intensidade, humor e observações
- Consultar histórico e mostrar registros na consulta médica
- Fazer backup e importar registros em JSON
- Interface adaptada para celular

## Abrir no VS Code
Abra a pasta do projeto e execute com uma extensão de servidor local, como Live Server. Você também pode abrir o arquivo index.html no navegador para testes simples.

## Privacidade e limitações
Os registros são armazenados apenas no localStorage do navegador e não sincronizam entre aparelhos. Limpar dados do navegador pode apagá-los. O armazenamento local não é adequado para compartilhar dispositivo sem proteção. Mantenha o repositório privado e nunca publique seus backups, que contêm informações de saúde.

Esta versão não possui contas, notificações ou lembretes automáticos e ainda precisa de testes antes de ser utilizada para acompanhar um tratamento. Não substitui orientação médica.
